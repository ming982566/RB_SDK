# RaceBear 第三方前端产品与交互规范

本文定义如何把公开 SDK 能力组织为可使用的控制面板。适用于桌面、Web/native bridge
或其它宿主，不要求采用 SimRacebear 的框架、配色、控件名或布局文件。
新建产品使用本文的默认组织；已有产品可保持原导航和设计系统，但必须覆盖对应操作、
状态和验收。字段、能力、范围与返回值以同包的 `include/RaceBearSDK.h` 和
[API 手册](RaceBearSDK_API.md) 为准，不根据本文增加不存在的接口。

从零开发先读 [AI 开发总入口](RaceBearSDK_AI_DEVELOPMENT.md)。
SDK 调用顺序见 [前端指南](RaceBearSDK_FRONTEND_GUIDE.md)。

## 1. 产品范围与主窗口

先确认用户要求的是完整控制面板、某个设备控制器还是嵌入式页面。完整控制面板的默认导航：

```text
总览
游戏与数据
  游戏 / 遥测
动感设置
  平台 / 动态滤波 / 运动增强 / 震动 / 风感 / 安全带
设备与输出
  输出连接 / CAN 设备 / 电机维护 / RGB / 仪表与屏幕
工具与设置
  插件 / 日志诊断 / 授权 / 系统与应用设置
开发工具（按范围提供）
  串口终端 / 自定义游戏与外部数据源 / 原始 JSON 与命令
```

默认主窗口采用导航、页面标题及操作栏、主内容、全局状态栏四个区域。
状态栏显示 SDK 版本、授权、当前游戏、数据源新鲜度、平台和输出连接摘要；
错误须附在对应动作旁，不能只在会被下一条消息覆盖的状态栏中显示。
总览首先显示实际状态或明确的空状态，不以营销介绍、API 清单或空面板作为首页。

导航节点可以合并为页内 Tab，但不能通过合并省掉独立配置域、选择器或测试停止路径。
辅助函数、兼容接口、只读查询和后台循环函数不需要逐个变成按钮。
完整功能是用户工作流闭环，不是导出函数数量达到某个数值。

## 2. 页面、容器与必要操作

表中“主从布局”表示可选择的目录列表加当前项详情；列表较短可改为标题栏下拉框。
“分组表单”表示无嵌套装饰卡片的参数区域，数据多时允许独立滚动。
窗口、Tab、抽屉的具体类型可随框架变化，操作语义与状态不能丢失。

| 页面与 API 域 | 推荐容器 | 必要内容与操作 |
|---|---|---|
| 总览：Runtime、State | 摘要网格、状态列表、可选趋势图 | 后端循环、授权、游戏、Source、Rig、输出、CAN、风感和安全带摘要；无游戏/未配置/离线状态 |
| 授权：Command、State | 状态区与激活表单 | 检查、激活、反激活及文档支持的动作；检查中、剩余时间、错误与输出许可；不把机器标识和令牌写日志 |
| 游戏：Game | 可搜索目录 + 详情 Tab | 安装与运行状态、稳定 GameKey、选择、配置、安装扫描、自动配置、文档支持的启动/停止动作 |
| 遥测：Telemetry | 可过滤数据表 + 可选图表 | 名称、单位、原始/处理值；无 Source 与不支持状态；稳定 Key 可在诊断详情显示 |
| 平台：Platform | 平台选择器 + 参数/保护/预览 Tab | 几何与行程、运行参数、V2 保护、保存与应用、导入导出；支持的 DOF、预览限制；切型前断开 |
| 手动姿态：ManualPose | 平台页的独立测试区或测试窗口 | 支持的每轴滑杆与数值、限位、测试启停、复位；测试状态始终可见，离开即复位 |
| 动态滤波：Dynamic | 方案选择器 + DOF Tab + 通道列表 + 当前通道表单 | 候选输入、通道增删/启用、全部有效滤波参数、保存应用、当前游戏绑定、导入导出；单路限制配置状态 |
| 运动增强：MotionEffect | 独立方案选择器 + 效果列表 + 路由表/编辑器 | 多路由增删、目标 DOF、比例/方向/阈值/频率/时长、效果默认值、保存应用 |
| 震动：Haptic | 同名动态方案选择器 + 效果列表/表单 | 启用、输出通道、增益及所有当前有效字段、单效果默认值、保存应用；不虚构独立目录或手动测试 API |
| 风感：Wind | 单配置分组表单 + 四路补偿表 + 测试区 | 输入速度范围、输出范围、曲线、总增益、四路增益/偏移、默认值、保存应用、测试停止 |
| 安全带算法：Seatbelt | 单配置表单 + 左右通道区 + 测试区 | 输入模式/来源、纵横向输入满量程、刹车门限、预紧、速度门限、左右比例/反向/平滑、保存应用与测试 |
| 安全带 CAN：SeatbeltCan | 所选输出实例的专用详情 Tab | 单/双通道、有效节点、Key、减速比/位置边界、回零设置、运行状态、释放锁定及显式重新启用；配置按输出实例归属 |
| 输出：Output | 输出实例主从布局 + 按类型显示的详情 | 增删实例、完整配置、Key 插入器、保存应用、连接断开、自动连接设置、当前状态；不能以编辑 Type 整数代替类型目录 |
| CAN：Can | 输出选择器 + UID 设备表 + 绑定/电机/健康 Tab | 刷新、设备详情、唯一逻辑索引、稳定绑定、单输出状态、人工恢复、适用类型的空闲下使能设置 |
| 电机维护：Can | 维护窗口 + 电机选择器 + 参数表 + 底部任务区 | 进入/退出维护、读取、写入与保存、勾选、导入导出、同类型同步、能力允许的恢复/重启/清故障/波特率设置 |
| 伺服升级：Can | 电机维护中的独立任务视图 | 目标确认、文件选择、启动、进度、错误和最终结果；维护状态及输出未运行条件，运行中锁定冲突动作 |
| RGB：Rgb | 设备选择区 + 灯带/图层/诊断/固件 Tab | UID 连接、四路映射、颜色/功率/超时、设备 Apply/Flash Save、主机效果 Save、图层排序和效果编辑、测试停止、固件任务 |
| 仪表：Dashboard | 模板/包主从布局 + 像素预览 + 输出目标 Tab | 内置与客户模板、导入删除、包页面选择、设计器入口；包句柄管理；预览状态与缺资源诊断 |
| VOCORE：VoCore | 仪表页内屏幕列表 + 每屏详情 | 枚举、打开关闭、亮度、旋转、自动重连、实际帧率与错误；每屏独立句柄 |
| 浏览器仪表：DashboardWeb | 仪表页内服务表单与状态区 | 地址/端口、打开关闭、访问地址、客户端数、编码/丢帧统计；与宿主预览和屏幕独立启停 |
| 插件：Plugin | 插件列表 + 详情 | 刷新、类型/版本/状态、支持的启动动作；刷新后重定位，不把目录索引持久化 |
| 串口：Serial | 端口选择/参数栏 + 收发终端 + 状态栏 | 创建打开关闭、文本/十六进制、收发、超时与重连、回调注销；可作为高级工具按范围提供 |
| 自定义游戏/外部源：Game、ExternalSource | 注册列表/配置表单 + 会话状态 + 联调工具 | 稳定源身份、传输协议与帧字段、打开关闭/提交、超时；与普通游戏选择区分，可按范围提供 |
| 系统/应用设置：System、Runtime | 分组表单 | SDK 系统设置和宿主语言/主题/窗口偏好分开存储；循环间隔控制放高级设置 |
| 日志/诊断：Log、Debug | 过滤日志表/文本区 + 详情面板 | 分级、搜索、暂停滚动、清空/导出、容量控制、持久化、可选监视器；不能单靠颜色表达错误 |
| JSON/命令：Data、Command | 独立高级编辑器 | 正式 JSON 解析、完整文档、校验/备份/回读与必要重载；命令只提供公开文档支持的项，不充当普通配置页 |

安全带算法配置是全局配置；安全带 CAN 配置按输出实例保存，不能共用一个索引或把两者当成同一结构。
设备控制能力以公开头、输出类型目录与运行能力共同决定；有枚举字符串不代表拥有该类型的全部底层维护协议。

## 3. 统一控件与字段清单

实现每页前为其结构体建立字段清单。每个成员至少标注：
公开字段、用户名称、读写性质、单位、有效范围、默认值来源、显示条件、依赖项、
控件、保存/应用目标和验证用例。每个成员必须有“编辑、只读展示、兼容保留、
保留字段或不在本次范围”的处置，不能因为通用表单生成器没处理就漏项。

| 数据语义 | 控件 | 规则 |
|---|---|---|
| 开关 | 勾选框/开关 | 只表示该字段的真实值；禁用状态和未勾选状态可区分 |
| 固定少量模式 | 单选组/分段选择 | 使用头文件枚举值；标签采用用户术语 |
| 目录项/设备/输入来源 | 下拉框或搜索选择器 | 显示名称、内部保存稳定身份；切换后立即刷新对应详情 |
| 数字 | 数字框，适用时配滑杆 | 单位与步长明确；保留编辑草稿，提交时才校验；有限浮点和整数边界分别处理 |
| 百分比 | 百分比数字框/滑杆 | 不把 0-1 的比率直接当成 0-100%；只按该字段合同换算 |
| 颜色 | 色块与颜色选择器 | 颜色值和亮度分别处理，读取回填 |
| 可重复项 | 可选择列表/表格 + 详情 | 支持文档允许的增删/重排；达到固定数组容量时阻止新增 |
| 状态/错误 | 状态文本、图标与详情 | 提供未知、离线、失败和更新时间；0 不等同于“不支持” |
| 文件 | 文件选择器 | UTF-8 路径、扩展名及内容验证、取消不更改草稿 |
| 长任务 | 进度条、阶段文本、错误明细 | 任务接受与最终成功分开；无取消 API 时不放置假取消按钮 |

未知枚举显示“当前版本不识别（值）”，保留原值，禁止静默映射为第一个选项。
兼容字段不提供看似生效的编辑控件。例如安全带当前未使用的碰撞参数和 FullSpeedKmh
读取后原样保存；MotionProtection 新 UI 使用 V2，V1 仅服务兼容调用，不并列制造两套保护开关。
UI 文案使用“平滑、软限幅、变化步长、限制强度”等用户语义；内部滤波算法名称和原始字段名
仅进入开发文档/诊断，不直接作为普通参数标签。

字段清单示例（最终完整清单由当前头与 API 手册逐成员生成）：

| 字段 | 用户展示与控件 | 处置与依赖 |
|---|---|---|
| `RB_WindEffectConfig.InputMinKmh/InputMaxKmh` | 起效/满输出车速，km/h 数字框 | 与彼此联动校验，不能把输入车速当成 SDK 原始速度 m/s |
| `RB_WindEffectConfig.MasterGainPercent` | 总输出，0-100% 数字框/滑杆 | 编辑草稿，分别 Apply/Save/回读 |
| `RB_FilterEffect.InGain` | 输入方向与增益，有符号小数 | 任意有限值按合同接受，不能统一限制到 0-100 |
| `RB_SeatbeltEffectConfig.FullSpeedKmh` | 普通页不显示 | 当前兼容字段，读取后保留，不制造无效调参控件 |
| `RB_OutputConfig.CANindex` | 绑定区显示逻辑索引 | 与 UID 绑定工作流一致，不能只改该字段来冒充稳定绑定 |
| `RB_RgbStripConfig.LedCount` | 灯数，整数 | 设备物理能力与逻辑映射同时校验，不采用通用表单的任意上限 |

前端字段元数据保存显示与校验信息，不改写 SDK 配置格式，也不通过反射猜测字段用途。

## 4. 六类可复用页面模板

### 4.1 目录与详情

```text
标题                    [搜索] [刷新] [新增/导入]
目录列表                当前项名称、有效状态
                        [分组参数 / 预览 / 诊断]
                        参数表单
                        字段错误与未保存提示
                        [重新读取] [应用] [保存] [导出]
```

切换到 B 前先处理 A 的草稿。加载成功后把身份、基线、草稿同时替换成 B；
加载失败显示 B 加载失败并禁用写入，不能显示 B 标题却保留 A 的可提交草稿。
保存时重新按稳定身份查当前索引；目标已删除则停止提交。
刷新导致所选项消失时显示“不可用”，不能自动选第一项后继续沿用旧草稿。

### 4.2 单配置表单

```text
标题                                  已保存/已修改/错误
输入来源与范围
输出曲线与总增益
通道表
[恢复默认草稿] [读取] [应用] [保存]
测试区：[开始测试] [测试值] [停止/归零]
```

默认值来自公开 GetDefault 接口；没有默认接口的类型按字段合同初始化或读取有效方案，
不得把全零结构体当成有效默认配置。默认值载入只更新草稿，除非用户明确提交。

### 4.3 设备与绑定

```text
输出实例选择器
设备 UID 列表 [刷新]    设备版本、协议、逻辑索引、冲突状态
                      输出当前绑定 / 在线目标 / 当前选择
                      [设置唯一索引] [绑定]
                      连接、Ready、故障、单输出电机状态
                      [连接] [断开] [请求恢复]
```

“当前选择的设备”和“输出已绑定的设备”是两个状态，未提交绑定时不得混写。
选中另一 UID 或另一输出时，设备信息、索引、绑定、电机和健康区都必须重新读取。
页面离开可以结束本页测试，但不应隐式断开正常运行输出。

### 4.4 实时监控

```text
[筛选/选择显示项]       数据时间/连接状态
名称 | 单位 | 原始值 | 处理值 | 支持状态
可选滚动趋势图
[暂停绘图] [清空曲线] [导出诊断]
```

暂停绘图不暂停 SDK 计算。只更新变化单元格，必要时虚拟化与限频。
状态读取失败保留上次有效值并标记陈旧；不能把错误转成全零后展示为新数据。
模拟数据仅在明确的演示模式或测试中使用，显示“模拟”，不能冒充实际连接。

### 4.5 长任务与升级

```text
目标身份、文件/来源摘要
前置条件与当前维护状态
[开始任务]
阶段、进度、已处理/相同/失败数量
结果、错误位置、重新读取/重试路径
```

启动后冻结目标身份，阻止冲突操作。参数同步可能部分写入，失败时提示重新读取，
不能宣称回滚。固件更新进度 100% 不代表最终成功，以最终状态及文档要求的重新枚举为准。
后台任务由宿主服务拥有，窗口关闭请求不销毁仍在调用 SDK 的线程。

安全带详情页须区分上电回零等待、正常回零、释放中、已释放锁定和保护故障。
释放中禁用运动命令；终态保护锁定后提供显式“重新启用”，不由定时刷新或重连自动调用。
同一按钮复用时应随状态明确改名，调用 `RB_SeatbeltCan_RequestReenable`，
而非RequestHoming。异步请求接受后保留处理中状态，Ready才表示恢复完成。
单路仅显示/校验有效电机；居中单路用左节点，双路节点不得重复。
保护故障不等于已回0，重新启用被拒绝时保留诊断和重试入口。
安全带输出间隔沿用本输出详情页的`OutPutTime`字段，单位明确标为ms；
生效范围2..1000，0/1/2使用2ms，4ms用于250Hz对比，2ms为默认500Hz目标。
不把该字段放入全局安全带算法配置，也不将目标频率显示为实测频率。
RGB帧率属于灯效配置，最高60Hz；提交成功不等于灯带已显示，RGB异常不自动恢复电机。

### 4.6 高级编辑与诊断

普通用户工作流应先有类型化页面。高级页显示数据包范围、格式校验、明确的提交动作、
备份/回读结果。命令参数用 JSON 序列化器，结果用 JSON 解析器；
不能通过搜索 `"ok":true` 判断成功。日志过滤、清空显示与清空 SDK 日志的语义分开。

## 5. 编辑、应用、保存与自动提交

页面同时维护最后读取的基线、编辑草稿、最后应用的版本以及任务状态。已保存不等于
已应用；已应用不等于已连接。界面分别显示结果，不能统一提示“成功”。

- Read：读取完整结构体并填入草稿；有未保存编辑时先按产品策略保存、放弃或取消。
- Apply：对支持的 API 更新运行态，保留草稿，不声称持久化或已连接。
- Save：校验整个草稿，保存到所属配置域，再回读业务字段；依赖的 Apply 是另一结果。
- Save 成功而 Apply 失败：明确显示“已保存，应用失败”；不要回滚成功的保存。
- Save 成功而回读失败：显示“已保存，回读未确认”，保留草稿和待重试状态。
- 导入：遵循对应 API 的草稿/落盘语义；`.rbmotor` 只生成草稿，平台/动态包可能覆盖配置，
  必须在动作前说明目标；失败不伪造成功或丢失原草稿。

默认使用显式 Apply/Save。用户要求自动保存时，可以对低风险配置使用约 1.2 秒防抖；
具体时间是产品策略，不是全部 SDK API 的统一行为。Flash 保存、固件升级、设备绑定、
电机写入、删除、连接、回零和授权操作保持显式动作。

数值框允许暂时为空、`-`、`0.` 等中间输入，不能每按一键就 clamp/格式化成最小值。
防抖到期只提交完整且合法的草稿；空值、非法值不保存，显示字段错误并保留输入。
回车/失焦/关闭时也走相同校验；关闭时无效草稿可选择返回修改或放弃。
语言切换、状态轮询、布局重建不能触发保存或覆盖正在编辑的文本。

切换项、页面关闭、刷新前取消旧防抖任务。任务携带原目标身份、目录版本与草稿修订号；
晚到结果只更新对应目标，不能覆盖新页面或新编辑。没有 SDK 并发版本控制接口时，
至少禁止宿主内对同一配置并发写入；外部应用并发改写时要求重新读取并由用户解决冲突。

## 6. 专项参数与依赖

### 动态与运动保护

DOF 标签和输入候选来自对应公开目录，不自行猜轴序。逐通道编辑而非只编辑第一个输入。
普通输入范围按候选 TelemetryKey 关联遥测目录的 Unit；候选本身没有 Name/Unit 成员。
通道效果 Key 用于效果选择，TelemetryKey 用于遥测定位，不相互替代。
InGain 支持负值及小数；各 0-100 标度不能误标成 ms/Hz。
单路变化限制、平台 V2 保护和原防削波是不同层级，不能共享同一个启用状态或阈值。
保护选项关闭时保留参数草稿、禁用依赖控件，按实际保存值回填；不自行添加 SDK 外滤波。

### RGB

输入由 `RB_Rgb_GetEffectInputCount/GetEffectInput` 按效果类型筛选；完整遥测目录只供专家诊断。
固定输入锁定来源，未支持的输入显示支持状态而非改绑。图层列表顺序映射 Priority，
每层具有独立段、输出、颜色、范围、频率、占空比等适用字段。

物理灯带数量以 `RB_RgbDeviceInfo.MaxOutputs/MaxLedsPerOutput` 和当前 API 合同为准。
逻辑映射另满足 `0 <= LogicalStart <= 600`、`0 <= LedCount <= 600 - LogicalStart`；
不能把 600 当成所有设备的物理灯数，也不能把某设备的 75 或 255 写成所有 RGB 的统一上限。
用户编辑 1-based 起止 LED，适配层转换成零基范围；越界在提交前提示。
当前安全带联动配置和可实际传输的 RGB 功能以当前公开手册为准，不以 DisplayMode
选项的存在承诺额外控制器能够接收像素。

普通刷新用内存 Snapshot/State；硬件读取和诊断另设明确动作。
主机效果保存与设备 Flash 保存分开。独立 RGB 设备与安全带输出使用各自身份和状态。

### 输出、维护与仪表

输出类型按目录填充，按所选类型显示 Serial/UDP/MMF/CAN 等相关字段；其它字段保留。
Key 插入器使用最新输出目录，模板编辑需保留 Start/周期/End 和各自间隔语义。
CAN UID 绑定、重复索引修复、健康恢复及维护遵循
[CAN 指南](RaceBearSDK_RB_CAN_GUIDE.md)；不直接发送私有 SDO/PDO。
仪表模板渲染、宿主预览、VOCORE、Web 是独立生命周期；
只隐藏预览时不能停止仍被已开启输出使用的渲染服务。

## 7. 状态、线程与反馈

| 对象 | 至少呈现的状态 |
|---|---|
| 页面 | 尚未加载、读取中、可编辑、已修改、提交中、失败、所选项不可用 |
| 后端 | 未初始化、启动中、运行、暂停、失败、关闭中、已关闭 |
| 连接 | 未连接、连接中、等待 Ready/回零、运行、断开中、故障/离线 |
| 任务 | 未开始、执行中、完成/失败、结果未确认；只有支持取消时显示取消中 |
| 数据 | 实时、陈旧、无 Source、不支持、读取失败、模拟 |

SDK 接受请求后继续读取实际状态，不能立即写“已连接/已恢复/已升级”。
长任务和可能访问 USB、磁盘、安装扫描或网络的调用放入宿主管理的任务服务；
UI 回调只接收副本。状态刷新、日志、目录和仪表渲染分别调度，不给每页重复创建后端循环。
任务可按配置域或设备串行排队，实时状态采用最新值覆盖；日志和曲线必须有容量上限。
普通页面离开与整个应用退出分开：退出流程需收敛所有任务、测试和自有句柄，再关闭 SDK。
具体模式见 Skill 的 `references/implementation-patterns.md`。

## 8. 文案、多语言与可访问性

宿主自己的语言资源与 SDK 配置分离；SDK 不提供通用 `RB_UI_*` 语言服务。
新产品默认支持用户要求的语言；未指定时以用户使用的语言为主，并将字符串集中为稳定 key。
若定位为多语言完整控制面板，建议提供简体、繁体和英文，但不能把建议当成用户硬性范围。
语言变化仅刷新标签、选项文本和格式，不改变 Key、UID、枚举值、草稿、勾选和运行参数。

状态同时使用文本和颜色；按钮具备键盘焦点和可读名称，图标有提示，错误关联字段。
在 100%、150%、200% DPI 和目标最小窗口下检查滚动、Tab 顺序、长译文、
文件路径、错误提示、缩放与预览。布局不足时换行/滚动，不能遮挡保存和停止按钮。
专业数据表可横向滚动，表单与操作区仍应可访问。

## 9. 视觉与用户工作流验收

每个已实现页面保存初始、已配置、编辑中和至少一种异常状态的截图；
按页面实际状态适用，不为了截图连接硬件。逐页确认控件确实可见、有事件、修改可回读，
没有占位按钮、空内容、裁切、重叠、乱码或用原始 JSON 代替应有的编辑器。
UI 自动化与像素检查只证明显示与交互，不能证明机械安全或设备实际动作。
完整测试矩阵见 [AI 开发总入口](RaceBearSDK_AI_DEVELOPMENT.md)。
